## 🧑‍💻 About

**검증된 디자인을 실제 서비스로 만들고, AI 에이전트로 문제를 자동화하는** 웹 풀스택 & AI 개발자입니다.

- 🏥 정적 프로토타입을 **WordPress 커스텀 테마 + CI/CD**로 이식해 **실제 운영 중인 서비스**로 완성 (도두리동물병원)
- 🤖 **LangGraph 멀티에이전트**로 출점 시뮬레이터·학습 도우미 등 AI 애플리케이션을 설계·구현
- 🧩 "디자인 자유도"와 "비개발자 운영"처럼 **충돌하는 요구를 구조로 푸는 것**에 관심이 많습니다

## 🚀 Projects

### 🏆 SPOTTER &nbsp;·&nbsp; AI 프랜차이즈 출점 시뮬레이터 &nbsp; [`SPOTTER`](https://github.com/soooojinn-prog/SPOTTER)

> 마포구 16개 행정동을 대상으로 프랜차이즈 신규 출점을 분석하는 **AI 시뮬레이터**. 잠식효과·경쟁환경·매출예측·법률리스크를 통합 분석해 **데이터 기반 출점 의사결정**을 지원합니다. &nbsp;**(팀 6인 / 3트랙)**

- 📈 시장분석 정확도 **50% → 87.5%**, Redis 캐싱으로 지연 **86.2% 감소**
